# Results, Red Sea Breakout 1988 (Intro 01), Sonnet 5.5 (low effort) on both sides

Blue = USS Yorktown + E-2C (Player taskforce), Red = Yemeni boats, MiG-21s and coastal sites (game AI helpers).
12 decision windows, 300 game-seconds each, 4x time compression. Costs are the Claude CLI's reported cost.

| Run | Setup | Result | Notes |
|---|---|---|---|
| 1 | no `engage`, briefing map for Blue | Red win, Yorktown lost ~16 min in | Blue never changed speed (13 kn), re-sent "weapons free" each window |
| 2 | no `engage`, + 3 standing instructions for Blue | Red win, Yorktown lost ~10 min in | Blue sped up once, still sailed into the boat cluster |
| 3 | `engage` available to both | Blue win, 13 kills / 0 losses | Blue 14 of 52 engage orders accepted, 38 refused (dead tracks) |
| 4 | same | Blue win, 10 kills / 0 losses | 13 of 43 accepted |
| 5 | + dead-track removal, receipts, weapon economy | Blue win, 10 kills / 0 losses, ended at window 6 | 14 of 19 accepted, 5-inch gun fired |

## Findings

- **Why Blue lost without `engage`:** a "weapons free" posture only lets the unit's own AI fire when *it* decides to; Blue's ships scored almost
  nothing while Red's AI-driven boats fired freely. With a direct order (`AI.AutoAttackByClick`, the same call as the player's click-to-attack)
  the same ship killed boats within a minute. Confirmed live before any match was run.
- **The game keeps a destroyed object's track flagged `live`** (age keeps growing), so commanders kept ordering shots at dead tracks until the
  runner removed them (learned from the game's own refusals) and labelled old tracks STALE.
- **`emitters active` only affects units that have a search radar**; radar state updates only when game time advances, so a paused-window
  readback of `radar_on` is not reliable.
- **Token cost:** Sonnet at low effort answers tersely (~300-1,500 output tokens per call). Haiku at low effort produced ~8k per call, so it cost
  more per match than Sonnet in this setup.
- **Red's play barely changes between runs** (swarm the cruiser's exact position); its boats spend ~800-1,000 gun rounds without a kill.
- **Mission end:** the game's own end-of-mission flag (`/truth.mission_ended`) is authoritative; the runner scores from it.

## Limits

Five games total, one scenario, runs 1 and 2 differ from 3-5 on purpose (the setup changed). Not a balance study. The sigma units of track
position uncertainty and the in-game marked-circle position were not independently verified.
